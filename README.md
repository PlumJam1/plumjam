# 플럼잼 — 인간의 마지막 출근

갓 컴공을 졸업한 개발자와 회사원들이 AI 침공에 맞서는 PC용 2D 웹게임 프로토타입. 냥코대전쟁의 병력·경제 운영과 팔라독의 주인공 조작을 참고한 하루 게임잼 프로젝트다.

## 실행

Node.js 22.x(22.12 이상), 24.x 또는 26 이상에서 실행한다. 전체 검증은 Node.js 26.4.0에서 통과했다.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

개발 서버는 http://127.0.0.1:5173, 정적 빌드 미리보기는 Vite가 터미널에 표시한 주소에서 열린다. 생성물은 `dist/`이며, 하위 경로 배포 시 `npm run build -- --base=/plumjam/`처럼 Vite base를 지정한다. 서버·계정 없이 로컬 브라우저에서 육성을 저장한다.

## 플레이

- `A/D` 또는 좌우 방향키: 주인공 이동. 병력 앞에 나가면 가장 가까운 공격 대상이 된다.
- `1`~`5`: 저장한 5칸 편성 순서로 병력 소환. 빈 칸은 사용할 수 없다.
- `J`: Hello World 발사. `K`: 방사형 `sleep()` 이동 슬로우. `L`: 주인공을 포함한 주변 아군 힐.
- `P`: 상점에서 해금한 `git push`로 주변 적 밀치기. `O`: `overclock()`으로 10초간 소환·다른 스킬의 쿨타임 진행 속도 2배.
- `U`: 수입과 자금 상한 강화. 소환·스킬·투자는 같은 자금을 쓴다.
- `R` 또는 1배·2배·3배 버튼: 전투 배속. 일시정지 중에도 선택하며 다음 전투는 1배로 시작한다.
- `Esc`: 일시정지. 브라우저 포커스가 사라져도 자동 일시정지한다.
- 장착한 스킬 버튼에 마우스를 올리거나 `Tab`으로 포커스하면 효과 수치가 보인다. Hello World는 오른쪽 사거리와 현재 예상 대상(적 유닛 또는 기지)을 보여주며, 투사체 이동 중 대상이 바뀔 수 있다. `sleep()`·힐·`git push`는 전장에 적용 범위와 대상을 표시하며, 밀치기는 도착 위치도 보여준다. 미리보기는 발사하거나 자금을 쓰지 않는다.

적 기지를 부수면 승리한다. 주인공 또는 아군 기지가 파괴되면 패배하며, 동시 파괴는 패배를 우선한다. 버튼 클릭으로도 소환·스킬·투자를 사용할 수 있다. 기본 공격은 없다.

## 프로토타입 범위

`1-1`~`1-5`, 근접·원거리·중장갑·긴급 배포 로봇, 마지막 GPT-4o 보스가 구현되어 있다. 클리어 XP를 원하는 캐릭터에 분배하고, 이미 깬 맵을 반복해서 XP를 얻는다. 최대 레벨은 10, 레벨 5부터 외형이 바뀐다. 서비스직은 5초마다 공격 유닛의 공격 준비 속도를 ×1.3으로 7초 지원한다. 심리상담사는 주변 아군과 개발자를 회복한다. 같은 버프는 중첩 대신 시간을 갱신하며, 주인공 버프의 남은 시간을 표시한다.

GPT-4o는 전용 HP 바와 격파 알림을 갖고, 등장 6초 뒤부터 9초마다 전방 범위 공격을 예고한다. 1.4초 동안 표시된 위험 구역을 벗어나 피할 수 있다. 구역은 예고 시 고정되므로 보스를 밀쳐도 움직이지 않으며, 보스가 죽으면 공격이 취소된다. `sleep()`은 이동만 늦추며, 감속 중인 적의 머리 왼쪽 위에 떠오르는 `Zzz`와 잔여 시간을 표시한다. `1-2`부터 등장하는 긴급 배포 로봇은 빠르지만 HP 60으로 기본 Hello World 한 발에 쓰러진다. `1-2`는 14초에 물량 공세를 예고하고 16초부터 긴급 배포 로봇 3기가 연속 등장한다. `1-3`은 원거리 압박, `1-4`는 중장갑 적 중심이며 돌진 웨이브는 없다. `1-5`는 혼합 보스전으로, 14초 예고 뒤 16초부터 긴급 배포 로봇 3기가 연속 등장한다.

새 게임은 Hello World만 보유·장착한다. 준비실 스킬 상점에서 `sleep()` 120 XP, 힐 160 XP, `git push` 240 XP, `overclock()` 200 XP로 영구 구매한다. 구매는 자동 장착하지 않으며 보유 스킬 중 최대 3개를 선택해 출근한다. Hello World도 한 칸이고, 모두 해제할 수도 있다. 전투 카드와 단축키는 실제 장착 스킬만 사용하며, 오른쪽 Hello World 버튼도 Hello World가 장착되어야 한다.

`git push` 전투 비용은 80, 쿨타임 12초, 반경 120이다. 일반 적은 논리적 전투 폭의 3배, 보스는 1배만큼 0.45초 동안 선형 이동하고, 유닛 오른쪽 끝이 적 기지 경계 x=585를 넘지 않는다. 목표에 도달하면 밀치기가 종료되며 HP 피해·기절은 없다. `overclock()` 비용은 100, 자체 쿨타임 30초다. 10초간 자신을 제외한 소환·스킬의 남은 쿨타임 진행만 2배로 만들며 공격·수입 주기 자체를 바꾸지 않는다.

전투 배속은 전투 모델의 시간 진행을 1·2·3배로 바꾼다. 이동·소환/스킬/지원/보스 타이머·수입·투사체·밀치기·스킬 연출이 같은 전투 시간을 따른다. 화면의 초 표시는 전투 시간이며 3배에서는 실제 1초에 전투 3초가 흐른다. 자금 비용·보상은 그대로이고 일시정지하면 시간이 멈춘다. 육성 저장에는 배속을 저장하지 않는다. 시각적인 사망 잔상과 UI 안내 만료는 가독성을 위해 실제 시간을 사용한다.

기존 v1 저장의 XP·레벨·진행·동료 편성·음소거·스킬 소유를 보존한다. 예전 스킬 소유 필드가 없으면 당시 기본 4종을 이관한다. 장착 필드가 없으면 보유 스킬을 Hello/sleep/heal/push/overclock 순서로 최대 3개 장착하고, 잘못된 장착만 보유·중복 없는 최대 3개로 회복한다.

Vue MVVM UI와 순수 TypeScript 전투 모델을 분리했다. `SceneLifetimeManager`가 씬 실행의 이벤트·ViewModel·오디오·표시 객체를 정리하고, 공용 텍스처와 저장 서비스는 앱 수명을 따른다. 짧은 원본 WebAudio 효과음은 첫 키보드/클릭 입력으로 활성화된다. 음소거는 준비실·전투 화면에서 조절하며 저장된다. 배경 음악은 이번 범위에 포함하지 않았다.

UI는 [냥코대전쟁 공식 안내](https://ponosgames.com/information/appli/battlecats/help/index.html)의 화면을 관찰하여 재구성했다. 초록 소용돌이 준비실, 종이 지도와 빨간 경로점, 5칸 편성 및 중앙 캐릭터 카드, 파워 업 카드, 상단 노란 자금과 하단 소환 카드를 적용한다. 전투는 왼쪽 원형 투자·가운데 5병력/최대 3장착 스킬 카드·오른쪽 Hello World 빠른 발사로 구성하며 기존 조작·전투 규칙을 유지한다. 승리·패배 화면은 큰 표제와 경험치 보상 띠로 재구성했다. 참고 화면과 구현 대응은 [UI_REFERENCE.md](UI_REFERENCE.md)에 기록했다.

## 에셋·출처

- 배경 3종과 캐릭터 이미지 17개(기본·레벨 5 외형 포함)는 ImageGen으로 생성했으며 원본 PNG를 수정 없이 사용한다. [생성 프롬프트와 목록](public/assets/generated/ASSET_PROMPTS.md), [원본 메타데이터](public/assets/generated/ASSET_METADATA.json).
- 서울과기대 심볼은 사용자가 지정한 필수 원본이다. [공식 심볼 안내](https://www.seoultech.ac.kr/intro/symbol/logo/symbol)에서 확보했고 파일은 `public/assets/bases/seoultech-symbol.gif`다. 외부 사용 사전 문의·상업적 사용 금지 조건을 SPEC에 기록했다.
- 효과음은 코드로 합성한 짧은 triangle 톤이다. 외부 오디오 샘플을 포함하지 않는다.
- UI 무늬 `public/assets/ui/office-swirl.svg`, `frame-spots.svg`, `paper-map.svg`는 독립 작성한 SVG이며 버튼·프레임·경로는 CSS로 제작한다. 원작 화면 PNG·캐릭터·소리 파일을 포함하지 않는다.
- 한국어 글꼴은 Google Fonts의 Noto Sans KR을 사용하며, 네트워크 없이도 시스템 sans-serif로 플레이할 수 있다.

[게임 명세](SPEC.md)와 [승인된 구현 계획](IMPLEMENTATION_PLAN.md)은 기획 기준이다. 초기 밸런스는 실제 플레이로 계속 다듬을 수 있다.

준비실의 출전 편성 탭에서 동료 6종 중 최대 5종을 선택한다. 첫 클리어로 기술직(1-1), 판사(1-2), 심리상담사(1-3)를 해금하며 자동 편성하지 않는다. 중복 편성은 불가하고 최소 1명을 유지한다. 기존 v1 저장 진행을 보존하고 신규 동료는 클리어 이력에서 소급 해금한다.
