# 플럼잼 — 인간의 마지막 출근

갓 컴공을 졸업한 개발자 **코딩 조**와 회사원들이 AI 침공에 맞서는 PC용 2D 웹게임 프로토타입. 냥코대전쟁의 병력·경제 운영과 팔라독의 주인공 조작을 참고한 하루 게임잼 프로젝트다.

## 실행

Node.js 22.x(22.12 이상), 24.x 또는 26 이상에서 실행한다. 전체 검증은 Node.js 26.4.0에서 통과했다.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

개발 서버는 http://127.0.0.1:5173, 정적 빌드 미리보기는 Vite가 터미널에 표시한 주소에서 열린다. 생성물은 `dist/`이며, 하위 경로 배포 시 `npm run build -- --base=/plumjam/`처럼 Vite base를 지정한다. 서버·계정 없이 로컬 브라우저에서 육성을 저장한다.

## 플레이

- `A/D` 또는 좌우 방향키: 주인공 이동. 병력 앞에 나가면 가장 가까운 공격 대상이 된다.
- `1`~`5`: 10칸 편성에서 현재 페이지의 5칸 병력 소환. `Q` 또는 이전/다음 버튼으로 병력 페이지를 바꾼다. 빈 칸은 사용할 수 없다.
- `J`: Hello World 발사. `K`: 방사형 `sleep()` 이동 슬로우. `L`: 주인공을 포함한 주변 아군 힐.
- `P`: 상점에서 해금한 `git push`로 주변 적 밀치기. `O`: `overclock()`으로 10초간 소환·다른 스킬의 쿨타임 진행 속도 2배.
- `I`: 구매·장착한 `foreach()` 문구를 포물선으로 던져 착지 범위의 적 유닛에 광역 피해.
- `U`: 수입과 자금 상한 강화. 소환·스킬·투자는 같은 자금을 쓴다.
- `R` 또는 1배·2배·3배 버튼: 전투 배속. 일시정지 중에도 선택하며 다음 전투는 1배로 시작한다.
- `Esc`: 일시정지. 브라우저 포커스가 사라져도 자동 일시정지한다.
- 장착한 스킬 버튼에 마우스를 올리거나 `Tab`으로 포커스하면 효과 수치가 보인다. Hello World는 오른쪽 사거리와 현재 예상 대상(적 유닛 또는 기지)을 보여주며, 투사체 이동 중 대상이 바뀔 수 있다. `sleep()`·힐·`git push`는 전장에 적용 범위와 대상을 표시하며, 밀치기는 도착 위치도 보여준다. 미리보기는 발사하거나 자금을 쓰지 않는다.

적 기지를 부수면 승리한다. 주인공 또는 아군 기지가 파괴되면 패배하며, 동시 파괴는 패배를 우선한다. 버튼 클릭으로도 소환·스킬·투자를 사용할 수 있다. 기본 공격은 없다.

## 프로토타입 범위

`1-1`~`1-5`와 `2-1`~`2-5`의 10개 스테이지, 근접·원거리·중장갑·긴급 배포 로봇, 각 장의 GPT-4o 보스전이 구현되어 있다. 클리어 XP를 원하는 캐릭터에 분배하고, 이미 깬 맵을 반복해서 XP를 얻는다. 최대 레벨은 10, 레벨 5부터 외형이 바뀐다. 서비스직은 5초마다 공격 유닛의 공격 준비 속도를 ×1.3으로 7초 지원한다. 심리상담사는 주변 아군과 개발자를 회복한다. 같은 버프는 중첩 대신 시간을 갱신하며, 주인공 버프의 남은 시간을 표시한다.

GPT-4o는 전용 HP 바와 격파 알림을 갖고, 등장 6초 뒤부터 9초마다 전방 범위 공격을 예고한다. 1.4초 동안 표시된 위험 구역을 벗어나 피할 수 있다. 구역은 예고 시 고정되므로 보스를 밀쳐도 움직이지 않으며, 보스가 죽으면 공격이 취소된다. `sleep()`은 이동만 늦추며, 감속 중인 적의 머리 왼쪽 위에 떠오르는 `Zzz`와 잔여 시간을 표시한다. `1-2`부터 등장하는 긴급 배포 로봇은 빠르지만 HP 60으로 기본 Hello World 한 발에 쓰러진다. `1-2`는 14초에 물량 공세를 예고하고 16초부터 긴급 배포 로봇 3기가 연속 등장한다. `1-3`은 원거리 압박, `1-4`는 중장갑 적 중심이며 돌진 웨이브는 없다. `1-5`는 혼합 보스전으로, 14초 예고 뒤 16초부터 긴급 배포 로봇 3기가 연속 등장한다.

새 게임은 Hello World만 보유·장착한다. 준비실 스킬 상점에서 `sleep()` 120 XP, 힐 160 XP, `git push` 240 XP, `overclock()` 200 XP, `foreach()` 220 XP로 영구 구매한다. 구매는 자동 장착하지 않으며 보유 스킬 중 최대 3개를 선택해 출근한다. Hello World도 한 칸이고, 모두 해제할 수도 있다. 전투 카드와 단축키는 실제 장착 스킬만 사용하며, 오른쪽 큰 행동 버튼은 첫 장착 스킬과 같은 비용·준비시간·고정 단축키를 사용한다. 스킬이 0개면 준비실 장착 안내를 표시한다.

`git push` 전투 비용은 65, 쿨타임 12초, 반경 120이다. 일반 적은 논리적 전투 폭의 3배, 보스는 1배만큼 0.45초 동안 선형 이동하고, 유닛 오른쪽 끝이 적 기지 경계 x=585를 넘지 않는다. 목표에 도달하면 밀치기가 종료되며 HP 피해·기절은 없다. `overclock()` 비용은 60, 자체 쿨타임 30초다. 10초간 자신을 제외한 소환·스킬의 남은 쿨타임 진행만 2배로 만들며 공격·수입 주기 자체를 바꾸지 않는다.

전투 배속은 전투 모델의 시간 진행을 1·2·3배로 바꾼다. 이동·소환/스킬/지원/보스 타이머·수입·투사체·밀치기·스킬 연출이 같은 전투 시간을 따른다. 화면의 초 표시는 전투 시간이며 3배에서는 실제 1초에 전투 3초가 흐른다. 자금 비용·보상은 그대로이고 일시정지하면 시간이 멈춘다. 육성 저장에는 배속을 저장하지 않는다. 시각적인 사망 잔상과 UI 안내 만료는 가독성을 위해 실제 시간을 사용한다.

기존 v1 저장의 XP·레벨·진행·동료 편성·음소거·스킬 소유를 보존한다. 예전 스킬 소유 필드가 없으면 당시 기본 4종을 이관한다. 장착 필드가 없으면 보유 스킬을 Hello/sleep/heal/push/overclock/foreach 순서로 최대 3개 장착하고, 잘못된 장착만 보유·중복 없는 최대 3개로 회복한다.

Vue MVVM UI와 순수 TypeScript 전투 모델을 분리했다. `SceneLifetimeManager`가 씬 실행의 이벤트·ViewModel·오디오·표시 객체를 정리하고, 공용 텍스처와 저장 서비스는 앱 수명을 따른다. 짧은 원본 WebAudio 효과음은 첫 키보드/클릭 입력으로 활성화된다. 음소거는 준비실·전투 화면에서 조절하며 저장된다. 배경 음악은 준비실·편성·파워 업·스킬 상점·지도에 Quirky, 일반 전투에 Tower Defense, GPT-4o가 등장하는 1-5·2-5에 Chiptune Boss Fight Music을 반복 재생한다. 첫 입력 후 재생하며 기존 음소거 설정을 공유한다. 전투 일시정지 중에는 음악도 멈추고 복귀하면 이어서 재생한다. 전투 배속은 음악 속도에 영향을 주지 않으며 결과 화면에서는 BGM을 멈춘다. 출처와 원본 파일 해시는 [음악 크레딧](public/assets/music/CREDITS.md)에 기록했다.

UI는 [냥코대전쟁 공식 안내](https://ponosgames.com/information/appli/battlecats/help/index.html)의 화면을 관찰하여 재구성했다. 초록 소용돌이 준비실, 종이 지도와 빨간 경로점, 10칸(5×2) 편성 및 중앙 캐릭터 카드, 파워 업 카드, 상단 노란 자금과 하단 소환 카드를 적용한다. 전투는 왼쪽 원형 투자·가운데 5개씩 두 페이지인 10병력 한 줄·오른쪽 Hello World 빠른 발사·우상단 최대 3장착 스킬 아이콘으로 구성하며 기존 조작·전투 규칙을 유지한다. 승리·패배 화면은 큰 표제와 경험치 보상 띠로 재구성했다. 참고 화면과 구현 대응은 [UI_REFERENCE.md](UI_REFERENCE.md)에 기록했다.

## 에셋·출처

- 배경 3종과 캐릭터 이미지 23개(기본·레벨 5 외형 포함)는 ImageGen으로 생성했으며 원본 PNG를 수정 없이 사용한다. [생성 프롬프트와 목록](public/assets/generated/ASSET_PROMPTS.md), [원본 메타데이터](public/assets/generated/ASSET_METADATA.json).
- 서울과기대 심볼은 사용자가 지정한 필수 원본이다. [공식 심볼 안내](https://www.seoultech.ac.kr/intro/symbol/logo/symbol)에서 확보했고 파일은 `public/assets/bases/seoultech-symbol.gif`다. 외부 사용 사전 문의·상업적 사용 금지 조건을 SPEC에 기록했다.
- 팀원이 제공한 `public/assets/bases/` 정상·파괴 기지 PNG를 함께 사용한다. 기지별 HP가 0이 되면 해당 파괴 외형으로 바꾸며, 개발자 패배만으로 기지를 파괴하지 않는다.
- 효과음은 코드로 합성한 짧은 triangle 톤이다. BGM 3곡은 사용자가 제공한 Pixabay 원본 MP3를 사용한다.
- UI 무늬 `public/assets/ui/office-swirl.svg`, `frame-spots.svg`, `paper-map.svg`는 독립 작성한 SVG이며 버튼·프레임·경로는 CSS로 제작한다. 원작 화면 PNG·캐릭터·소리 파일을 포함하지 않는다.
- 한국어 글꼴은 Google Fonts의 Noto Sans KR을 사용하며, 네트워크 없이도 시스템 sans-serif로 플레이할 수 있다.

[게임 명세](SPEC.md)와 [승인된 구현 계획](IMPLEMENTATION_PLAN.md)은 기획 기준이다. 초기 밸런스는 실제 플레이로 계속 다듬을 수 있다.

준비실의 출전 편성 탭에서 동료 9종 중 최대 10칸을 편성한다. 첫 클리어로 기술직(1-1), 판사(1-2), 심리상담사·소방관(1-3), 운동선수·가수(1-4)를 해금하며 자동 편성하지 않는다. 중복 편성은 불가하고 최소 1명을 유지한다. 기존 v1 저장 진행을 보존하고 신규 동료는 클리어 이력에서 소급 해금한다.


운동선수는 비용 180의 빠른 근접 공격수로, 타격한 적 유닛을 최대 20만큼 0.15초 동안 밀친다. 기지는 밀지 않으며 진행 중인 더 강한 git push를 단축하지 않는다. 소방관은 HP 110·공격 개시 거리 85·총 분사 거리 115의 가까운 범위 공격수다. 총피해 48×레벨 배율을 1초 동안 4틱으로 나눠 적용하며 공격 주기 2.75초·비용 200·소환 대기 8초다. 체력이 낮아 전열 보호가 필요하다. 가수는 아군 공격/방어와 적 공격력 약화를 제공한다. 판사는 0.25초 준비 후 0.35초 동안 대상을 추적하는 망치를 낙하시킨다. foreach는 개발자 앞 180·반경 90·0.7초 비행 뒤 적 유닛에만 기본 피해 95×레벨·공격 버프를 적용하며 기지는 제외한다. 신규 스킬도 구매만으로 자동 장착하지 않는다. 기존 5칸 저장은 같은 위치 뒤에 빈 칸 5개를 추가하고 기존 육성·소유·진행을 보존한다.


## 브라우저 확인 기록 — 2026-10-04

기존 저장을 유지한 실제 UI 조작으로 3배속 1-1을 두 번 클리어해 XP 60→180→300을 확인했다. foreach를 220 XP에 구매해 XP 80이 남았으며 구매 직후 장착은 바뀌지 않았다. 선택한 스킬 칸에 foreach를 장착하여 최대 3개를 유지했다. 신규 도트 6종을 포함한 이미지 요청은 정상이며, 파워 업의 중앙 카드·강화 버튼·필요 XP 표시를 확인했다. 720p·1080p에서 10칸 편성의 4:3 프레임과 큰 중앙 도트, 파워 업의 왼쪽 강화 버튼·카드 하단 XP, 전투의 전장 80%·병력 한 줄 20% 배치를 확인했다. I키 foreach 발사·포물선 문구·일시정지 비행 정지·재시작 초기화를 확인했고, 별도 신규 저장도 XP 0·기본 동료 3종+빈 칸 7개·Hello만 장착한 상태로 시작했다. 두 저장에서 이미지 깨짐과 콘솔 경고·오류는 없었다. 모델·저장·UI 경계를 포함한 132개 테스트(16파일), 타입 검사와 프로덕션 빌드가 통과했다.

역할별 비용·체력·화력과 지원 효과를 조정했다. 서비스직은 공격속도 +30%, 가수는 공격 +20%·아군 받는 피해/적 피해 −15%를 맡는다. [밸런싱 근거와 재현 방법](BALANCE.md)은 자동 정책의 성과와 실제 플레이 검증의 한계를 구분해 기록한다.

방어·보조 스킬 전투 비용은 sleep 55·힐 80·git push 65·overclock 60이다. overclock은 수입을 늘리지 않으니 자금을 비축한 뒤 사용하는 편이 좋다. XP 상점 가격·스킬 쿨타임은 그대로다.


밸런싱 후 신규 저장(XP 0·전원 레벨 1·Hello만 보유)으로 실제 1-1을 3배속에서 클리어했다. 근접 2명·원거리 2명·서비스직 1명만 소환하고 개발자 스킬·경제 투자를 사용하지 않았으며, HUD 1:14에 개발자 HP 320·기지 HP 900으로 승리해 120 XP와 기술직 해금을 받았다. 그 재화로 sleep을 구매했을 때 자동 장착하지 않았고, 두 번째 칸에 장착한 새 전투에서 1배 초기화·55자금 사용·일시정지/복귀 정리를 확인했다. 이미지 깨짐과 콘솔 경고·오류는 없었다. 최종 140개 테스트(17파일)·타입 검사·빌드가 통과했다.

## 2장 — 두 번째 교대

1장 5개 단계의 전투 수치를 유지하고 2-1~2-5를 추가했다. 긴급 배포 물량 → 원거리 후열 → 중장갑 → 혼합 압박 → GPT-4o 재등장 순으로 기존 병력·스킬 조합을 시험한다. 2-5는 시작과 전투 35초에 GPT-4o가 등장하며 실제 피해·예고·사망은 각 보스가 따로 관리한다. 성장·전투 상황에 따라 첫 보스가 두 번째 등장 전에 죽을 수 있어 항상 동시 두 마리라고 가정하지 않는다.

지도에서 장을 선택하고 각 장의 5개 스테이지를 확인한다. 1-5 다음은 2-1, 현재 마지막은 2-5다. 예전 1-5 완전 클리어 저장은 2-1만 추가 해금하며 XP·레벨·동료/스킬 편성·음소거를 유지한다. 부분 진행과 잘못된 저장의 검증은 그대로다.

[새 장 시뮬레이션 원본](docs/chapter-two-audit.json)은 첫 클리어 보상만으로 10개를 진행한다. 0.5초/1초 판단 정책에서 전체 693.7/697.6 전투초, 신규 장의 각 단계는 66.6~89.5/69.1~85.7초에 클리어했다. 이는 자동 정책 결과이며 사람의 평균 플레이 시간은 아니다. 반복 파밍과 무상 스킬·레벨 지급 없이 2장 진입에 개발자 레벨 5·기술직 레벨 3, 마지막에는 개발자 7·핵심 동료 3~5를 사용했다.

```sh
npm run balance -- --chapters --output /tmp/plumjam-chapters.json
```


2장 지도는 실제 부분 진행 v1 저장(1-1 클리어·XP 0·보유 스킬 2개)을 유지한 브라우저에서 확인했다. 1-2 기본 선택, 잠긴 2장 5카드/5노드·2-5의 GPT-4o 2회/650 XP 안내·출진 차단, 장별 선택 기억, 800×600·1280×720·1920×1080의 프레임과 이미지/콘솔 상태가 정상이다. 예전 1-5 완전 클리어 이관과 10단계 승리/보상·2보스 격파는 공개 모델 테스트·시뮬레이션으로 검증했으며 브라우저에서 10개를 모두 플레이했다고 주장하지 않는다. 최종 162개 테스트(20파일)·타입 검사·빌드가 통과했다.

전투 기본 카메라는 팔라독처럼 주인공을 따라가는 1.5배 근접 시점이다. V키나 보기 버튼으로 1배 전체 전장을 확인한다. 일시정지 중에도 전환할 수 있고, 새 전투·재시작은 근접 시점으로 돌아간다. 카메라만 바꾸며 실제 사거리·유닛 폭·밀치기·자금·쿨타임은 그대로다. 초기 적 기지가 화면 밖이어도 양쪽 기지 HP는 HUD에 계속 보인다.

근접 시점은 실제 PC 800×600·1280×720·1920×1080에서 확인했다. 확대된 캐릭터와 전선·병력 카드가 UI에 가리지 않고, 전체 보기에서는 양쪽 기지를 확인할 수 있다. 일시정지 V 전환에서 자금·시간이 유지되며, 키보드로 스킬에서 설명 영역으로 이동해 아래 내용을 읽어도 설명이 사라지지 않는다. 콘솔 오류·경고는 없었고 171개 테스트(22파일)·타입 검사·빌드가 통과했다.

## 출근 이야기

첫 로딩이 끝난 준비실 실행에서 미열람 프롤로그를 자동으로 보여준다. 1-5와 2-5 보스 승리 뒤에는 해당 후일담을 보여주고 기존 승리 화면으로 돌아간다. 이미 본 이야기는 반복 승리 때 자동 재생하지 않는다. 타이틀·준비실의 이야기 보관함에서 다시 읽거나 잠긴 편의 해금 조건을 확인한다. 이전/다음·방향키·Enter와 넘기기/Escape를 사용하며 자동 넘김·타자 효과는 없다.

코딩 조의 실종된 여동생 기억을 따라하는 R-17이 등장한다. 강제로 복제된 기록을 좇은 조와 로봇은 원본을 대신하는 대신 새 선택을 한다. R-17은 새벽이라는 이름을 고르고, 두 챕터의 13페이지 안에서 상실과 함께 살아갈 결말을 맺는다. 기존 보관함에서 변경된 이야기를 재읽을 수 있으며 열람 기록을 초기화하지 않는다.

읽기를 마치거나 넘겼을 때만 `seenStoryIds`를 저장한다. 이전 저장에 이 필드가 없거나 잘못된 항목이 있어도 XP·레벨·클리어·동료/스킬 편성·음소거를 보존한다. 과거 보스 클리어의 미열람 이야기는 준비실에서 순서대로 따라 읽을 수 있다. 스토리 표시 중에는 전투 단축키와 배경 조작을 막으며, 별도 Phaser 씬이나 새 전투 판정은 추가하지 않는다.

실제 800×600·1280×720·1920×1080에서 본문 19~22px와 이전/다음/넘기기, 연속 방향키 페이지 전환의 본문 포커스·스크롤 리셋, 보관함 재읽기/잠김/원래 버튼 복귀, 읽음 저장 후 새로고침 비반복을 확인했다. 기존 실제 부분 진행의 XP·스킬·클리어와 투자/배속 원본 PNG 표시를 보존했고 이미지 깨짐·콘솔 오류/경고는 없었다. 보스 승리 뒤 자동 스토리와 승리 보상 복귀는 공개 모델 테스트로 검증했으며 브라우저에서 보스까지 새로 플레이한 기록은 아니다. 전체 185개 테스트(24파일)·타입 검사·빌드 및 독립 관련 53개 테스트 검증을 통과했다.


## 보스 예고 보호와 장착 스킬 주 행동 (2026-10-04)

새 전투는 보스 예고 자동감속을 켠 상태로 시작한다. 선택한 2/3배와 별개로 보스 예고 중 실제 진행만 1배로 낮추고, 모든 예고가 끝나면 최근 선택 배속으로 돌아간다. 기존 배속 버튼·R은 선택값을 유지하며 보스 줄의 짧은 보호 배지와 일시정지 창에서 선택/현재 배속을 확인한다. 일시정지 중 ON/OFF를 무료로 바꿀 수 있고 이 옵션은 저장하지 않는다. 대기시간 표기는 게임초다.

하단 주 행동은 첫 장착 스킬이다. 위 스킬 카드와 같은 상태·비용·키·미리보기·준비시간을 공유하며, hover/포커스는 발사하지 않는다. 장착 0개도 유지한다. 이야기 읽기와 보관함의 상단 소리 버튼은 기존 음소거 저장·BGM/효과음 경로를 사용하고, 배경 inert와 모달 키보드 조작을 유지한다.


실제 800×600에서 이야기·보관함의 소리 ON→OFF→ON과 native Enter가 페이지를 넘기지 않는 것을 확인했다. sleep만 장착한 하단 버튼은 K·55자금과 위 카드의 준비시간을 공유했고, 0개 장착은 숨은 Hello 없이 비활성 안내를 보였다. 일시정지 중 자금/시간을 유지하며 3배 선택·예고 보호 OFF/ON을 변경하고 새 실행의 1배·ON 초기화를 확인했다. 보스 예고 중 실제 감속·복구와 피해 시간 경계는 모델 테스트로 검증했으며 브라우저 보스 플레이 기록은 아니다. 전체 214개 테스트(28파일)·타입 검사·빌드가 통과했다.


## 제출용 플레이 흐름 (2026-10-04)

타이틀·준비실의 작은 플레이 방법·크레딧 메뉴에서 전체 키와 승패·육성·출처를 읽는다. 전투에서는 먼저 일시정지하고 조작 설명을 연다. 안내 자체는 전투를 멈추거나 시간을 진행하지 않으며, 닫으면 원래 화면과 포커스로 돌아간다. 소리 설정을 공유하고, 씬 변경·실행 종료에는 안내를 바로 닫는다.

첫 전투 안내는 소환 → 선택적 투자 → 실제 장착 스킬 → 이동/후퇴를 한 단계씩 보여준다. 이미 한 행동을 다시 요구하지 않고 읽기만 다음으로 넘길 수도 있다. 새 동료 카드에서 편성 화면으로 이동하면 해당 동료와 기존 칸 또는 첫 빈 칸을 살펴보며, 확정하기 전에는 편성이 저장되지 않는다. 마지막 출근은 10스테이지 클리어·엔딩 열람 상태와 크레딧을 보여주고 준비실로 돌아가거나 다시 도전할 수 있다. 기존 보상·반복 클리어와 자동 저장을 유지한다.
