# 밸런스·UI/UX 추가 개선 검토

2026-10-04 · 기준 `5a532396766a71824c9d096c48a9b0e3e7b65587` · **제안 기록이며 게임 코드·수치 변경은 없다.** 우선순위는 보스 배속 보호 → 미장착 주 행동 → 새 동료 안내다.

## 확인한 배속 경계

같은 실제 획득 XP 프로필·`balanced` 정책으로 비교했다. 시간은 게임 초이며 모든 행에서 아군 기지는 HP 900이었다.

| 보스 / 코딩 조 레벨 | 1배 | 2배 | 3배 |
| --- | --- | --- | --- |
| 1-5 / Lv.3 | 승리 93.7초 · HP 416/416 | 승리 98.6초 · HP 416/416 | 패배 23.4초 · HP 0 |
| 2-5 / Lv.7 | 승리 85.7초 · HP 608/608 | 승리 86.7초 · HP 608/608 | 패배 29.3초 · HP 0 |

방법: [공개 모델 감사 함수](../scripts/balanceSimulation.ts)의 `simulateFreshCampaign(1, 2)`로 각 스테이지 첫 클리어 보상만 사용해 육성·스킬 구매를 진행했다. 순차 10단계 승리 시간은 `49.2, 51.7, 62.9, 69.5, 93.7, 71.6, 69.1, 74.8, 69.4, 85.7`초다. 보스 비교는 같은 획득 프로필, 월드 스텝 0.1초, 판단 간격 `1 실제초 × 배속`, 반응 지연 `0.5 실제초 × 배속`을 사용했다.
배속 비교는 브라우저에서 `set-speed`를 실행한 측정이 아니라, 정상 속도 `simulateBattle` 모델에서 같은 실시간 입력·반응 간격을 게임 초로 환산한 정책 비교다.

예고 1.4 게임초는 1/2/3배에서 실제 1.4/0.7/0.4667초다. **고정 판단·반응 정책의 결과이며 사람의 승률이나 모두의 3배 패배를 뜻하지 않는다.** 배속은 이동 판단의 과도한 진행에도 영향을 주므로 예고 시간만의 독립 인과 효과로 해석하지 않는다. 같은 획득 능력치·Hello/힐/foreach와 초기 동료 3종 편성만으로도 1배에서 1-5는 110초·HP 341, 2-5는 107.1초·HP 464로 승리했다. 초기 편성 유지가 필패라는 근거도 없다.

## 우선 개선안

- **P1 · 보스 배속 보호 선택지:** 공격 예고 중 잠시 1배로 전환하고 안전하게 원래 속도로 복귀하는 옵션을 검토한다. 현재 3배 선택은 보존하며, 적 피해·예고 기본값부터 바꾸지 않는다.
- **P1 · 장착한 스킬을 하단 주 행동으로:** 실제 800×600 UI에서 Hello를 해제하고 sleep만 장착해도 하단 Hello World가 `장착 필요`·`aria-disabled=true`로 남았다. 폭 97.76px로 전장 768px의 약 13%다. 차단 동작은 정상이고 공간·우선순위 문제다. 첫 장착 스킬 또는 선택한 대표 스킬을 보여주고 0개일 때는 빈 상태를 제안한다. 기존 병력 5칸 배치는 유지한다. [확인 화면](/Users/hajung/.codex/visualizations/2026/10/03/01a100da-e5fd-7e01-83d9-31275d1340ce/audit-hello-slot-oct04.png)
- **P2 · 새 동료부터 안내:** 결과의 새 동료 이름을 편성 진입 CTA와 살펴보기 선택에 연결한다. 편성 화면의 기본 선택이 근접 회사원인 현재 흐름보다 발견하기 쉽다. 자동 장착·교체는 하지 않는다.

아래는 소스·UI를 근거로 한 후속 UX 제안이며 기능 오류 확정은 아니다.

- 첫 전투의 큰 전체 단축키 목록을 **소환 → 투자 → 후퇴** 3개 짧은 안내로 나눈다.
- 근접 1.5배 시점의 화면 밖 적·기지 위치를 얇은 미니맵 또는 가장자리 화살표로 보완한다. 기존 `V` 전체 보기는 유지한다.
- 투자 버튼에서 다음 수입·상한을 바로 읽게 하거나, 행동과 별개의 포커스 가능한 설명을 제공한다. 현재 혜택 안내는 주로 hover에 있고 native `disabled` 버튼은 포커스를 받지 못한다. [MDN 설명](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/disabled)
- **P2 · BGM 통합 후 추가 (`5cf85ed`, 위 기준과 별도):** 이야기 중 Lobby BGM이 재생될 수 있지만 game-header가 `inert`라 소리 토글에 접근하려면 읽기를 종료해야 한다. StoryScreen 안에도 같은 음소거 버튼 추가를 제안한다. 실제 UI에서 ON→OFF→ON 표시 복원·이야기 컨트롤 3개·header `inert`를 확인했으며, 출력 오디오 청취·녹음 검증은 아니다.

추가 수입만으로 계산한 투자 회수 시간은 `130/8=16.25`, `230/10=23`, `380/12≈31.67` 게임초다. 이를 근거로 무조건 투자하거나 가격을 바꾸지는 않는다. 지원 유닛의 강화는 HP만 늘어나는 경우가 있으므로 역할별 비교를 추가한 뒤 수치 변경을 판단한다.

## 후속 구현 — 2026-10-04

위 측정과 제안은 검토 당시 기록으로 유지한다. 보스 예고 보호를 새 실행 기본 ON의 무료 옵션으로 구현하고 선택 배속과 실제 진행 배속을 분리했다. 하단 주 행동은 첫 장착 스킬로 연결하여 Hello 미장착 공간을 해소하며 빈 장착도 안내한다. 이야기/보관함 내부 소리 버튼도 기존 음소거 경로에 연결했다. 이 절은 구현 기록이며 기존 배속 정책 표를 새 보호 옵션의 사람 승률 결과로 바꾸지 않는다. 새 동료 안내 등 다른 제안은 여전히 후속 검토다.


## 제출 준비의 후속 구현 — 2026-10-04

새 동료 안내를 원본 도트·역할·비용 카드와 편성 미리보기 진입으로 구현했다. 해금한 동료의 기존 칸 또는 첫 빈 칸을 선택하며 실제 저장은 유저 확정 뒤에만 수행한다. 첫 전투의 긴 키 목록은 한 단계 안내로 줄이고 전체 조작은 플레이 방법에 담았다. 최종 결과·크레딧·준비실 복귀와 무료 읽기 모달을 추가했으며 미니맵과 투자 설명 확장 등의 다른 제안은 여전히 후속 검토다. 과거 측정 표와 사람 승률 해석 경계는 유지한다.
